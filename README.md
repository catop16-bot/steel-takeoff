# 鋼構算量

網頁版鋼結構建模算量程式，操作方式對照 Tekla Structures：建立軸線（格子線）與高程，放置柱、大梁、小梁、斜撐、桁條、多邊形鋼板（不做接頭），每支構件即時算出長度、單位重、重量、密度與塗裝面積，依 Tekla 規則編號後匯出 Excel／CSV／PDF 報表。

純前端，不需要伺服器：專案自動存在瀏覽器（IndexedDB），也可另存成 `.sqp` 專案檔。

線上版：<https://catop16-bot.github.io/steel-takeoff/>（推到 `main` 後由 GitHub Actions 自動測試、建置並部署）

### 安裝成應用程式

線上版可以安裝成應用程式（PWA）：有自己的圖示與視窗，第一次開啟後會把整個程式（含 DWG／PDF 解析元件）存在電腦上，離線也能用。

- Chrome／Edge：按功能區右上角「⤓ 安裝」，或網址列右側的安裝圖示。安裝後可對 .sqp／.dwg／.dxf／.pdf 按右鍵用「鋼構算量」開啟。
- Mac 的 Safari：「檔案」→「加入 Dock」。iPhone／iPad：「分享」→「加入主畫面」。
- 有新版時右下角會提示「重新整理以更新」。

圖示由 `node scripts/make-icons.mjs` 產生（`public/icons/`）；離線快取清單在建置時由 `vite.config.ts` 寫進 `dist/sw.js`。

## 開發

Node 安裝在 `~/.local/node/bin`：

```bash
export PATH="$HOME/.local/node/bin:$PATH"
npm install
npm run dev      # http://localhost:5180
npm test         # 單元測試（型錄、斷面解析、算量、編號、報表匯出）
npm run build    # 型別檢查＋打包到 dist/
```

## 第 1 批：建模核心＋算量報表

- 軸線：Tekla 座標語法 `0 4*6000 7500`、標籤自動遞增、原點與旋轉；修改後立面視圖自動同步。
- 高程：樓層表、快速產生、樓地板面積（kg/m² 用）；磁性高程（改高程時吸附的構件跟著移動）。
- 視圖：3D、各樓層平面、各軸線立面；視圖深度裁切；Ctrl+P 切換 3D。
- 視窗版面（仿 Blender）：窗格數量不限、可任意分割。拖曳窗格邊界調整大小（雙擊邊界平均分配、右鍵可合併／交換）；從窗格角落往內拖＝分割，拖進相鄰窗格＝合併（按住 ⌘／Ctrl＝交換）；標題列按鈕可左右／上下分割、最大化（Ctrl+Space 或雙擊標題列）、關閉；功能區「視圖」有單一／左右／三格／四格預設。平面、立面視圖改變窗格大小時比例尺不變。版面隨專案儲存。
- 介面大小：左側專案瀏覽、右側屬性面板拖曳邊界調整寬度，拖到最窄收合（T／N 開關，同 Blender）；上方工具列拖曳下緣放大縮小，往上拖到底或雙擊頁籤收合，收合後點頁籤暫時展開；「視圖 → 介面」可重設。介面大小存在這台電腦的瀏覽器。
- 構件：柱、大梁、小梁、斜撐、桁條、多邊形鋼板；Tekla 式位置（平面上、旋轉、深度）與端部偏移。
- 鎖點：端點、中點、軸線交點、線上、自由點；正交；數值輸入（長度、`@dx,dy,dz`、`x,y,z`）。
- 斷面庫：JIS G 3192／CNS 1490 H 型鋼、I 型鋼、槽鋼、角鋼、CT；JIS G 3444 圓管；JIS G 3466 方管；JIS G 3350 輕型鋼；型錄外尺寸自動參數化（BH、BOX、PL、FB、圓鋼）。
- 算量：重量 = 斷面積 × 長度 × 材質密度；斷面積依 JIS 公式（含圓角），全部型錄以表列單位重交叉檢核。
- 報表：依編號、斷面材料、樓層（含 kg/m²）、類型、材質、全部構件；Excel（含合計公式）、CSV（UTF-8 BOM）、列印／PDF。

## 第 2 批：圖紙匯入與對照

- 格式：DXF（自寫解析器：$DWGCODEPAGE 判斷 Big5／GBK／UTF-8、`\M+`／`\U+` 控制碼、MTEXT 格式碼、巢狀圖塊、圖塊屬性、陣列插入、標註圖塊、凸度弧、雲形線）、DWG（@mlightcad/libredwg-web，背景執行緒載入約 8 MB 的 wasm）、PDF（pdf.js 擷取向量路徑與文字，依筆畫顏色分層，另存點陣底圖）。
- 匯入：「圖紙 → 匯入圖紙」或把檔案拖進視窗；選擇放在哪個樓層平面或軸線立面、圖面單位（PDF 為出圖比例）、文字編碼。
- 對位：「兩點對位」先點圖上兩點（軸線交點），再點模型對應兩點；DXF／DWG 預設比例不變，PDF 會一併校正比例（S 鍵切換）。
- 顯示：平面／立面視圖圖紙畫在構件上方、3D 視圖照深度；可調透明度、單色、文字、各圖層開關。
- 鎖點：建模時可鎖到圖紙的端點、中點、交點、圓心與線上（狀態列「圖紙」開關）。
- 儲存：圖紙幾何另存在瀏覽器 IndexedDB；存成 `.sqp` 專案檔時一併嵌入。
- 測試圖檔：`node tests/fixtures/make-fixtures.mjs` 產生 `tests/fixtures/sample-plan.dxf`／`.pdf`（與內建範例相同的軸線，但原點偏移）。

## 第 3 批：半自動辨識（功能區「辨識」）

- 辨識軸線：從軸線圖層（名稱含 AXIS／GRID／軸，或線型 CENTER）找長直線，合併虛線、分出兩個方向，讀線端泡泡（圓）內的標籤；可旋轉的圖也行。套用時可把圖紙移到原點、軸線轉正。
- 辨識高程：讀「2FL +4.200」「RFL ▽+8.40」「B1F -3.500」，或名稱與高程分開但同列的文字；有小數點或小於 300 視為公尺。
- 框選斷面表：在圖上框選構件表，抽出「編號 → 斷面」（同一段文字、左右排列、上下對齊三種排法），存成專案的斷面對照表。
- 辨識梁柱：選梁圖層（或在圖上點一條梁線）、柱圖層；雙線梁取中心線、端點延伸到軸線或大梁中心線、大梁在柱位分跨、小梁遇大梁分跨；每個文字指派給最近的一跨（避開端部），連續梁只標一次也能沿用；斷面依文字或對照表。候選以橘線（缺斷面紅線）預覽，勾選確認後建立。
- 一鍵佈梁柱：軸線範圍內的交點放柱（每層一支）、沿軸線在交點間佈大梁，已存在的略過。

## 第 4 批：進階編輯與收尾

- 移動（⌘M）、複製（⌘C）：選基準點與目標點，可輸入 `@dx,dy,dz` 或距離。陣列複製（dX/dY/dZ × 份數）、鏡射複製（在平面或立面點兩點）、旋轉（選中心、輸入角度）、分割（點構件上的位置）。
- 磁性軸線：修改軸線間距、原點或角度時，端點在軸線上的構件依標籤跟著移動（可關閉）；磁性高程同前。
- 選取篩選：只選得到勾選的構件類型。
- 重複構件檢查：找出完全重複（同類型同斷面同端點）與共線重疊的構件，可一鍵刪除完全重複的。
- 構件標註：平面、立面視圖顯示編號或斷面。
- 報表：可隱藏欄位（Excel、CSV、列印都套用）、公司名稱表頭。
